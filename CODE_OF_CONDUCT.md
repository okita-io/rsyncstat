# Code of Conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep feedback constructive, and do not harass anyone. Maintainers may remove comments, commits or contributors that violate this.

To report a problem, use GitHub's private "Report content" tools or contact the maintainers through [GitHub Security Advisories](https://github.com/okita-io/rsyncstat/security/advisories/new) if no other private channel is listed. Reports are handled confidentially.
